# AltoMe images

Thư mục này dùng để lưu các ảnh minh họa của AltoMe, ví dụ:

- Ảnh giao diện AppManager hiển thị alarm.
- Ảnh sơ đồ luồng Alertmanager → AltoMe → AppManager.
- Ảnh triển khai Docker hoặc kiểm tra vận hành.

Anh có thể upload trực tiếp các file `.png`, `.jpg`, `.jpeg`, `.webp` vào thư mục này trên GitHub.

Không đặt API key, password, token hoặc thông tin nhạy cảm trong ảnh trước khi upload.
